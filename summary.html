Canvas Course Manager

A browser-based GUI for managing Canvas LMS courses, built with Flask and vanilla JavaScript. Run it locally and manage your entire course from a single interface — no clicking through Canvas menus. Version 1.0.

9 Integrated Tabs

  • Browse — Expandable module tree with items grouped by type (assignments, quizzes, pages, discussions)
  • Calendar — Month-by-month view showing assignment availability windows and quiz due dates; click any event to jump to its editor
  • Student Progress — Ranked scores, Canvas access statistics, missing/late submissions, per-assignment averages
  • File Manager — Two-panel view: local files on the left, Canvas files on the right, with drag-and-drop upload, file type filters, and resizable panels
  • Assignment Editor — Create, edit, publish/unpublish, and delete assignments with side-by-side HTML source and rendered preview; AI generation and review
  • Quiz Editor — Create quizzes with 6 question types, live HTML preview; AI generation and review
  • Page Editor — Edit Canvas wiki pages with side-by-side HTML source and live preview
  • LaTeX → Canvas — Side-by-side editor that converts LaTeX equations into Canvas equation image format, with AI-assisted LaTeX generation
  • AI Assistant — Chat interface powered by Claude with a skills/macros panel for quiz generation, exam creation, assignment generation, and review tasks

AI-Powered Workflows

  • Generate — Select source materials (Canvas pages, local files, free text), enter a topic, and AI generates quizzes, exams, or assignments
  • Review — One-click AI review of quizzes and assignments for ambiguous wording, factual errors, and missing information
  • Customizable Prompts — All AI actions use editable prompt templates; click the gear icon to customize how the AI generates and reviews content

Prerequisites

  • Python 3.10+ with Flask (pip install flask requests)
  • A Canvas LMS account with a valid API token
  • Anthropic API key (or Bedrock gateway) for AI features
  • (Optional) Claude Code for the AI Assistant chat tab

Quick Start

1. Clone the repo

git clone https://github.com/astrostubbs/CanvasFrontEnd.git

2. Install dependencies

pip install -r requirements.txt

3. Set environment variables

cp .env.example .env then edit

4. Run

set -a; source .env; set +a; python3 canvas_gui.py

Open http://localhost:5050 in your browser.
