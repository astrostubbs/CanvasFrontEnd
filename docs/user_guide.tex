\section{Getting Started}
% ══════════════════════════════════════════════════════

\subsection{Overview}

Canvas Course Manager is a locally-run web application that gives instructors a unified interface for managing Canvas LMS courses. Instead of navigating between multiple Canvas web pages, you get a single dashboard with tabs for browsing course content, managing files, editing assignments and quizzes, tracking student progress, and viewing a course calendar.

\begin{center}
\begin{tikzpicture}[
    box/.style={draw=accent, fill=navy!15, rounded corners=3pt, minimum width=2.2cm, minimum height=0.8cm, text=darkbg, font=\small, align=center},
    arrow/.style={-{Stealth[length=3mm]}, thick, accent}
]
    \node[box] (browser) at (0,0) {Your\\Browser};
    \node[box] (flask) at (4,0) {Flask\\Server};
    \node[box] (canvas) at (8,0) {Canvas\\LMS API};
    \node[box, fill=crimson!15] (local) at (4,-2) {Local\\Files};
    \draw[arrow] (browser) -- (flask);
    \draw[arrow] (flask) -- (canvas);
    \draw[arrow] (flask) -- (local);
    \node[font=\tiny, text=gray] at (2,0.3) {localhost:5050};
    \node[font=\tiny, text=gray] at (6,0.3) {REST API};
\end{tikzpicture}
\end{center}

The Flask server acts as a proxy between your browser and the Canvas API, handling authentication and parallel data fetching to keep the UI responsive.

\subsection{Installation}

\begin{enumerate}[leftmargin=*]
    \item \textbf{Clone the repository:}
\begin{lstlisting}[language=bash]
git clone https://github.com/astrostubbs/CanvasFrontEnd.git
cd CanvasFrontEnd
\end{lstlisting}

    \item \textbf{Install Python dependencies:}
\begin{lstlisting}[language=bash]
pip install -r requirements.txt
\end{lstlisting}

    \item \textbf{Configure your Canvas API token} (see Section~\ref{sec:apikey}).

    \item \textbf{Run the server:}
\begin{lstlisting}[language=bash]
set -a; source .env; set +a
python canvas_gui.py
\end{lstlisting}

    \item Open \url{http://localhost:5050} in your browser.
\end{enumerate}

\subsection{Obtaining a Canvas API Token}
\label{sec:apikey}

\begin{enumerate}[leftmargin=*]
    \item Log in to your Canvas instance (e.g., \texttt{canvas.instructure.com}).
    \item Navigate to \textbf{Account} $\rightarrow$ \textbf{Settings}.
    \item Scroll down to \textbf{Approved Integrations}.
    \item Click \textbf{+ New Access Token}.
    \item Enter a purpose (e.g., ``Course Manager'') and optionally set an expiry date.
    \item Click \textbf{Generate Token} and copy the token immediately.
\end{enumerate}

\begin{warnbox}
Your API token grants full access to your Canvas account. Never commit it to version control or share it. Store it in a \texttt{.env} file (which is git-ignored) or export it as an environment variable.
\end{warnbox}

\subsection{Environment Configuration}

Copy the example configuration and fill in your values:

\begin{lstlisting}[language=bash]
cp .env.example .env
\end{lstlisting}

Edit \texttt{.env} with your settings:

\begin{lstlisting}
CANVAS_API_TOKEN=1234~AbCdEfGhIjKlMnOpQrStUvWxYz
CANVAS_API_URL=https://canvas.instructure.com/api/v1
LOCAL_ROOT=~/Documents/MyCourse
\end{lstlisting}

\begin{table}[h]
\centering
\caption{Environment Variables}
\begin{tabular}{lll}
\toprule
\textbf{Variable} & \textbf{Required} & \textbf{Description} \\
\midrule
\texttt{CANVAS\_API\_TOKEN} & Yes & Your Canvas personal access token \\
\texttt{CANVAS\_API\_URL} & Yes & Canvas API base URL (with \texttt{/api/v1}) \\
\texttt{LOCAL\_ROOT} & No & Root directory for local file browser \\
\bottomrule
\end{tabular}
\end{table}

\begin{enumerate}

Low page views combined with low scores may indicate a student who isn't engaging with the material. High page views with low scores may indicate a student who is struggling despite effort.

\subsection{Missing Assignments}

A sorted list of students who have missing submissions, ordered by the number of missing assignments (most first). Hover over a row to see which specific assignments are missing.

\begin{warnbox}
The ``missing'' flag comes from Canvas. An assignment is marked missing if it is past due and the student has not submitted anything. If you use ``on paper'' submission types, Canvas may incorrectly flag those as missing.
\end{warnbox}

\subsection{Late Submissions}

Similar to the missing list, this shows students with late submissions and the count of late work.

\subsection{Per-Assignment Averages}

A bar chart showing the class average score for each graded assignment. This helps identify assignments that were particularly challenging (low average) or straightforward (high average).

\subsection{Uploading Files to Canvas}

\begin{enumerate}[leftmargin=*]
    \item In the left panel, locate the file you want to upload.
    \item \textbf{Drag} the file from the left panel and \textbf{drop} it onto a Canvas folder in the right panel.
    \item A confirmation dialog appears letting you choose the destination folder.
    \item Click \textbf{Upload} to transfer the file.
\end{enumerate}

The upload uses Canvas's three-step upload process (notify, upload, confirm) and handles it automatically.

\subsection{Browsing Canvas Files}

Click any folder in the right panel to expand it and see its contents. Click a file to open/download it in a new tab.

\subsection{Local File Navigation}

The local file panel includes navigation controls at the top:
\begin{itemize}[leftmargin=*]
    \item \textbf{$\uparrow$ Up} --- go to the parent directory.
    \item \textbf{Home} --- go to your home directory (\texttt{\textasciitilde}).
    \item \textbf{Desktop} --- go to \texttt{\textasciitilde/Desktop}.
    \item \textbf{Click path display} --- type any path to navigate directly.
    \item \textbf{Double-click a folder} --- enter that folder as the new root.
\end{itemize}

\section{\LaTeX{} to Canvas Converter}
% ══════════════════════════════════════════════════════

The \textbf{LaTeX $\to$ Canvas} tab solves one of the most frustrating problems in Canvas: getting mathematical equations to display correctly. Canvas does not natively support \LaTeX{} input, but it does render equations via specially encoded image URLs. This tab automates the conversion.

\subsection{How It Works}

The tab provides a side-by-side editor:
\begin{itemize}[leftmargin=*]
    \item \textbf{Left panel:} An HTML editor where you write your page content.
    \item \textbf{Right panel:} A live preview showing how Canvas will render it.
\end{itemize}

Canvas equations use a special URL format:
\begin{lstlisting}
https://canvas.instructure.com/equation_images/<encoded-latex>
\end{lstlisting}
where the \LaTeX{} is double-URL-encoded. This tab handles the encoding automatically.

\subsection{Inserting Equations}

\begin{enumerate}[leftmargin=*]
    \item Type \LaTeX{} in the \textbf{equation bar} (e.g., \texttt{\textbackslash frac\{dN\}\{dM\} = kM\^{}\{-\textbackslash alpha\}}).
    \item A live preview appears showing how the equation will render.
    \item Click \textbf{Insert Equation} to insert the Canvas-formatted \texttt{<img>} tag at the cursor position in the editor.
    \item The right panel updates to show the rendered result.
\end{enumerate}

\subsection{Quick-Insert Symbols}

A toolbar provides one-click buttons for common \LaTeX{} symbols: fractions, square roots, integrals, summations, Greek letters ($\alpha, \beta, \gamma, \lambda$), solar mass ($M_\odot$), operators ($\pm, \approx, \leq, \geq, \partial, \nabla$), and more.

\subsection{Batch Conversion}

If you prefer to write content using \texttt{\$...\$} (inline) and \texttt{\$\$...\$\$} (display) delimiters, click \textbf{Convert All \$...\$} to automatically find all \LaTeX{} delimiters in the editor and replace them with Canvas equation image tags.

\begin{tipbox}
This is the fastest workflow: write your page content using familiar \LaTeX{} delimiters, then click one button to convert everything to Canvas format.
\end{tipbox}

\subsection{AI-Assisted \LaTeX{}}

Click \textbf{AI Assist} and describe the equation you need in plain English (e.g., ``Stefan-Boltzmann law'' or ``integral of x squared from 0 to infinity''). Claude will generate the \LaTeX{} code and populate the equation bar for you.

\subsection{Loading and Saving Canvas Pages}

\begin{itemize}[leftmargin=*]
    \item \textbf{Load from Canvas Page:} Fetches an existing page's HTML content into the editor for editing.
    \item \textbf{Save to Canvas Page:} Pushes the editor content directly to a Canvas page.
    \item \textbf{Copy HTML:} Copies the raw HTML to your clipboard for pasting elsewhere.
\end{itemize}

\section{Prompt Templates}
\label{sec:prompts}
% ══════════════════════════════════════════════════════

Prompt templates are editable ``recipes'' that the AI uses for specific tasks. They are stored in \texttt{prompts.json} in the project directory and can be edited through the GUI.

\subsection{Opening the Prompt Editor}

Click the \textbf{gear icon} (\(\circledS\)) in the application header bar (next to the course selector). This opens a modal with:
\begin{itemize}[leftmargin=*]
    \item A \textbf{list of templates} on the left.
    \item An \textbf{editing panel} on the right showing the selected template's name, description, and prompt text.
\end{itemize}

\subsection{Template Placeholders}

Prompt templates use curly-brace placeholders that get filled in at runtime:

\begin{table}[h]
\centering
\begin{tabular}{ll}
\toprule
\textbf{Placeholder} & \textbf{Filled with} \\
\midrule
\texttt{\{topic\}} & The user's topic or instructions \\
\texttt{\{content\}} & Content being reviewed (quiz text, assignment description) \\
\texttt{\{source\_material\}} & Concatenated text from selected source materials \\
\texttt{\{num\_questions\}} & Number of questions to generate \\
\texttt{\{question\_type\}} & Question type (multiple\_choice, essay, etc.) \\
\texttt{\{points\}} & Points per question \\
\bottomrule
\end{tabular}
\end{table}

\subsection{Example: Custom Review Prompt}

Suppose you want a template that specifically checks for Bloom's taxonomy coverage:

\begin{lstlisting}[title={Example custom prompt template}]
You are an exam designer for a college-level course. Analyze the
following questions and classify each by Bloom's taxonomy level
(Remember, Understand, Apply, Analyze, Evaluate, Create).

Questions:
{content}

For each question:
1. State the Bloom's level
2. Explain your classification
3. Suggest how to elevate the question to a higher level

Provide a summary table at the end.
\end{lstlisting}

\subsection{Default Templates}

\begin{description}[leftmargin=*]
    \item[\texttt{generate\_quiz}] Generates quiz questions with structured JSON output. Handles MC, T/F, short answer, essay, and mixed types.
    \item[\texttt{generate\_from\_reading}] Like \texttt{generate\_quiz} but emphasizes comprehension over memorization when source material is provided.
    \item[\texttt{generate\_assignment}] Creates a complete assignment with title, HTML instructions, and grading criteria.
    \item[\texttt{generate\_exam}] Creates a comprehensive exam with mixed question types and varied cognitive levels.
    \item[\texttt{review\_quiz}] Identifies ambiguous wording, multiple-correct-answer problems, trick questions, and factual errors.
    \item[\texttt{review\_assignment}] Checks assignment descriptions for clarity, missing information, and grading criteria.
    \item[\texttt{review\_exam}] Assesses coverage, difficulty balance, Bloom's levels, time management, and point distribution.
\end{description}

\subsection{Adding and Deleting Templates}

\begin{itemize}[leftmargin=*]
    \item Click \textbf{+ New Prompt} in the editor header to create a new template. You'll be asked for a key name.
    \item Fill in the name, description, and prompt text. Use placeholders where appropriate.
    \item Click \textbf{Save} to persist changes to \texttt{prompts.json}.
    \item Click \textbf{Delete} to remove a template.
\end{itemize}

\section{Common Workflows}
% ══════════════════════════════════════════════════════

\subsection{Weekly Check-In: Are Students On Track?}

\begin{enumerate}[leftmargin=*]
    \item Open the \textbf{Students} tab.
    \item Check the \textbf{Missing Assignments} card — follow up with students who have multiple missing items.
    \item Review the \textbf{Grade Distribution} — if it's skewed low, consider reviewing the material.
    \item Look at \textbf{Per-Assignment Averages} — a low average on a specific assignment may indicate unclear instructions.
\end{enumerate}

\subsection{Preparing Next Week's Content}

\begin{enumerate}[leftmargin=*]
    \item Open the \textbf{Calendar} tab to see what's due and when.
    \item Switch to \textbf{Assignments} to create or edit upcoming assignments. Set due dates and availability windows.
    \item Use the \textbf{Files} tab to upload any new materials (lecture slides, datasets, readings) by dragging from local to Canvas.
    \item Switch to \textbf{Quizzes} to create a review quiz. Use \textbf{AI Assistant} to generate question ideas.
\end{enumerate}

\subsection{Creating a Quiz from Scratch}

\begin{enumerate}[leftmargin=*]
    \item Go to the \textbf{Quizzes} tab and click \textbf{+ New}.
    \item Enter a title and set the quiz type (Graded Quiz, Practice Quiz, etc.).
    \item Click \textbf{Create Quiz}.
    \item Click \textbf{+ Add Question}. Choose a question type from the grid (e.g., Multiple Choice).
    \item Fill in the question text, points, and answers. Click \textbf{Add Question}.
    \item Repeat for each question --- you can mix different types.
    \item When ready, click \textbf{Publish} to make it available to students.
\end{enumerate}

\subsection{AI Quiz from Course Readings}

\begin{enumerate}[leftmargin=*]
    \item Go to the \textbf{Quizzes} tab and click \textbf{AI Generate}.
    \item Enter a topic: ``Stellar evolution and the Hertzsprung-Russell diagram.''
    \item Click \textbf{+ Add Sources}, switch to \textbf{Local Files}, navigate to your lecture notes PDF, check the box, and click \textbf{Add Selected}.
    \item Set: 8 questions, Mix, 2 pts each.
    \item Click \textbf{Generate Questions}. Wait for the AI to produce questions.
    \item Review each generated question. Edit wording, fix answers, adjust points, delete weak questions.
    \item Click \textbf{Create Draft Quiz in Canvas}.
    \item The quiz appears in your sidebar. Click \textbf{AI Review} to check for issues.
    \item Fix any flagged problems, then \textbf{Publish}.
\end{enumerate}

\subsection{AI-Generated Problem Set}

\begin{enumerate}[leftmargin=*]
    \item Go to the \textbf{Assignments} tab and click \textbf{AI Generate}.
    \item Enter: ``Problem set on orbital mechanics. Include derivations, numerical calculations, and one Python coding problem.''
    \item Add sources: select the relevant Canvas page and a local textbook chapter PDF.
    \item Select \textbf{Problem Set}, 100 points.
    \item Click \textbf{Generate Assignment}.
    \item Edit the generated HTML description in the split editor. The live preview shows how students will see it.
    \item Click \textbf{Create Draft Assignment in Canvas}.
    \item Open the draft, click \textbf{AI Review} for a clarity check, then \textbf{Publish}.
\end{enumerate}

\subsection{Reviewing an Existing Exam}

\begin{enumerate}[leftmargin=*]
    \item Load the quiz/exam in the \textbf{Quizzes} tab.
    \item Click \textbf{AI Review} in the header.
    \item The AI streams a detailed review: question-by-question analysis of wording, difficulty, potential issues.
    \item For each flagged issue, edit the question text directly in the side-by-side editor.
    \item Click \textbf{Save} on each modified question.
\end{enumerate}

\subsection{Uploading Course Materials}

\begin{enumerate}[leftmargin=*]
    \item Go to the \textbf{Files} tab.
    \item In the left panel, navigate to the file you want to upload. Use the $\uparrow$~Up button, Home, or Desktop buttons to navigate.
    \item Optionally use the type filter (PDF, Code, etc.) to find specific files.
    \item Drag the file onto the target Canvas folder in the right panel.
    \item Confirm the upload in the dialog.
\end{enumerate}

\subsection{Customizing an AI Prompt}

\begin{enumerate}[leftmargin=*]
    \item Click the \textbf{gear icon} in the header.
    \item Select a template from the left panel (e.g., ``Review Quiz for Issues'').
    \item Edit the prompt text. For example, add: ``Also check that each question maps to a specific learning objective.''
    \item Click \textbf{Save}.
    \item The next time you use AI Review or the skill macro, it will use your updated prompt.
\end{enumerate}

\section{Security Considerations}
% ══════════════════════════════════════════════════════

\begin{itemize}[leftmargin=*]
    \item The application runs \textbf{locally only} on \texttt{127.0.0.1:5050}. It is not designed for public deployment.
    \item Your Canvas API token is never sent to any service other than your Canvas instance.
    \item The \texttt{.gitignore} excludes \texttt{.env} and \texttt{canvas.mcp.json} to prevent accidental token commits.
    \item The AI Assistant inherits your shell environment. Ensure your Anthropic/Bedrock API keys are set via environment variables, not hardcoded.
    \item If you share this tool with others, remind them to generate their own API tokens.
\end{itemize}
